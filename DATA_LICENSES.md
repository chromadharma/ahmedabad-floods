# Data licences

The code in this repository is MIT-licensed (see `LICENSE`). The data it
downloads is not, and keeps its own terms. None of the raw data is
redistributed here.

- **Copernicus GLO-30 DEM:** free of charge for any use, with attribution to
  the Copernicus programme (ESA / DLR / Airbus). The exact attribution wording
  is to be copied from the licence document before publication.
- **FABDEM v1-2** (University of Bristol; Hawker et al. 2022): **CC BY-NC-SA
  4.0.** Non-commercial use only, and ShareAlike applies: any depth raster or
  map derived from FABDEM that this project publishes carries the same licence.
- **Sentinel-1** (Copernicus, ESA): free and open. Credit: "Contains modified
  Copernicus Sentinel data 2026".
- **DataMeet Municipal Spatial Data** (Ahmedabad wards): CC BY-SA 2.5 India.
- **OpenStreetMap** roads, hospitals and waterways: © OpenStreetMap
  contributors, Open Database Licence (ODbL) 1.0.
- **Press reports** used for rainfall and river figures: the publishers'
  copyright. Figures transcribed from them are cited by URL; the pages are
  not republished.
- **CartoDEM** (ISRO Bhuvan): not used. Bhuvan's terms forbid derivative works
  and redistribution (DESIGN D3).
